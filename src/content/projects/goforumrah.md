## Project Overview

GoForUmrah was developed during my internship at **Illiyin Studio** (Nov 2023 – Apr 2024). The product aims to simplify and digitize the discovery and booking process for Umrah travel packages, offering users a transparent, intuitive, and modern experience.

### Key Contributions & Responsibilities
- Translated design systems from Figma into responsive, accessible Next.js client pages.
- Structured reusable UI components utilizing Tailwind CSS utility classes.
- Integrated package listing displays, detailed itineraries, and booking inquiry workflows.
- Maintained clean version control with Git and collaborated within a fast-moving studio environment.

### Technologies Used
- **Next.js & React**: Component modularity and client-side page rendering.
- **JavaScript (ES6+)**: Dynamic UI states and interactive filtering.
- **Tailwind CSS**: Responsive layouts and tokenized spacing.
- **Git & GitHub**: Collaborative version management.
