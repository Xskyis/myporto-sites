## Project Overview

JayaCamp is a comprehensive rental management platform engineered as a collaborative **Project-Based Learning (PBL)** initiative at Politeknik Negeri Malang. It addresses logistical bottlenecks encountered by outdoor gear rental providers by digitizing stock allocations, reservation dates, and returns.

### Highlights & Architecture
- **Admin Dashboard**: Leveraged Filament PHP v3 for rapid, type-safe administrative CRUD operations and real-time inventory management.
- **Client Rental Catalog**: Built with Tailwind CSS and Laravel Blade for seamless customer browsing of tents, cooking kits, and climbing gear.
- **Relational Integrity**: Designed robust MySQL schema relationships ensuring zero overbooking collisions across overlapping rental dates.
